# 🌱 HORI2ON-AutoCare

**Dashboard visual de monitoreo y mantenimiento predictivo para fotobiorreactores instalados en autobuses urbanos.**

Proyecto creado para el Imagine Planet Challenge.

---

## 🚀 Descripción

Horizon AutoCare es una aplicación desarrollada con **Streamlit** que permite:

- Monitorear en tiempo real los parámetros críticos del fotobiorreactor: pH, temperatura y concentración de CO₂.
- Generar alertas automáticas cuando los valores están fuera de rango.
- Analizar datos históricos para predecir posibles fallos futuros.
- Visualizar tendencias mediante gráficas interactivas.

---

## 🛠️ Tecnologías utilizadas

- **Python**
- **Streamlit**
- **Matplotlib**
